# Klea App Requirements & Specifications

## User Experience

### 1. Reflection Prompts
- Swipeable card interface (Tinder/Hinge style)
- Users can swipe through prompts
- Select prompts to answer based on interest/emotion
- Condition-specific questions based on recovery pathway
- Focus on emotional support and coping mechanisms

### 2. Symptom Tracking
- **Photo & Video Support**: Capture visual documentation of symptoms
- **Calendar-Style History**: BeReal-inspired interface
  - Swipeable calendar view of daily symptom entries
  - Thumbnails of submitted photos visible in calendar
  - Click to expand and view full photos
  - Display stats and optional notes below photos

### 3. Tracked Symptoms
- Mobility (replaced "anxiety")
- Appetite
- Overall mood
- Motivation
- Energy levels
- Pain levels
- Sleep quality
- Customizable symptoms

### 4. Multimedia Journaling
- **Video Vlogging**: Record recovery journey
- **Photo Journaling**: Capture moments and symptoms
- **Written Entries**: Traditional journal entries with optional prompts
- **Audio Notes**: Quick voice memos (optional)

### 5. Color Consistency
- All pages should match the color scheme from the edited first page
- Maintain cohesive visual design across all screens

## Key Interactions

### Prompt Swiping
- Card-based interface
- Swipe left/right or up/down to browse
- Tap card to view full prompt
- Answer prompt or skip to next
- Track answered prompts

### Symptom Calendar View
- Month/week view options
- Thumbnails show submitted photos
- Tap to expand and view details
- Display:
  - Date and time
  - Symptom statistics
  - Mood/severity indicators
  - Optional user notes
- Swipe between days/weeks

### Settings - Symptom Tracking
- Toggle tracked symptoms on/off
- Add custom symptoms
- Set tracking frequency
- Notification preferences
- Default severity scales

## Accessibility
- Large, readable text
- Simple navigation
- Accommodates users in recovery state
- Minimal cognitive load

## Privacy & Security
- All data stored locally or encrypted
- No sharing without explicit consent
- HIPAA compliance considerations
- Secure authentication
